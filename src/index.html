    → 远程地址填 gh443:me/todo-data.git

    尚未检查

    通过 SSH 与服务器 SQLite 双向同步加密清单。多台设备通过同一配对码共享清单与密钥；各设备开启自动同步后，会定时拉取并刷新。

    相对目录位于登录用户的家目录，支持 ~/。首次使用请点「确认服务器指纹」，与服务器后台指纹核对一致后保存。登录密码保存在系统密钥管理器中；加密 SSH 私钥请先加入 ssh-agent。

    业务数据使用 AES-256-GCM 在本机加密，密钥由系统密钥管理器自动保存与读取。服务器只收到密文；密钥不可用时停止上传。本机仍使用原有 JSON 存储。

    配对码包含清单解密密钥。可让多台设备加入同一清单。只通过可信方式传递，勿公开分享。每台设备仍需自行配置 SSH 登录凭据。

    不同字段自动合并；同一字段由逻辑版本和设备标识决胜。删除与普通编辑冲突时保留删除，可通过撤销删除重新恢复。
